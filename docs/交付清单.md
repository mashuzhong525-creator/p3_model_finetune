## 云端训练执行项（租卡一天，按量）

- [ ] RT0：AutoDL 租卡（3090/4090）+ LLaMA-Factory + ModelScope 下载 Qwen2.5-1.5B-Instruct（约 3.2GB）
- [ ] RT1：`HOST=root@<云IP> bash train/upload_data.sh` 上传数据与配置
- [ ] RT2：云端 `bash train/prepare_data.sh` 注册数据；`bash train/run_train.sh` 完成训练（日志 + loss + adapter）
- [ ] RT3：云端 `bash train/export_quantize.sh` 产出 `qwen1.5b-q4_k_m.gguf`（约 1GB）并 scp 回本地
- [ ] RT3b：训练/量化完成后立即在 AutoDL 控制台关机释放实例（按量计费）
