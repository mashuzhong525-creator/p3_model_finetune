# AI 初稿：训练数据（v0.1）

> 状态：**AI 初稿，未经人工抽检**｜日期：2026-08-19｜下一步：按《抽检记录表.md》人工抽检 ≥20% 后定稿 v1.0

## 1. 初稿内容

- 规模：300 条问答对（alpaca 格式：instruction / input / output）
- 五能力分层：术语适配 60、忠实回答 75、多片段整合 45、证据引用 60、资料不足拒答 60
- 划分：`train.json`（270）/ `val.json`（30），随机种子 42
- 契约校验：`pytest tests/test_data_format.py` → **5 passed**（总数、字段、证据编号合法、拒答收尾、空 input 必拒答）

## 2. 生成方式

- 素材：`素材语料库.md`（S 绿建标准 / D 双碳政策 / C 碳核算，来源见文末来源清单）
- 提示词：`../prompts/训练数据构建提示词.md`（五能力分层模板 + 质量校验提示词）
- 口径：现行标准一律按 **GB/T 50378-2019（2024年版）** 表述
- 生成者：AI 批量生成（未调用 DeepSeek API；如需 API 生成路径，后续可用提示词模板 + DeepSeek key 重跑）

## 3. 已知局限（抽检重点）

1. ~~冲突样本为构造示例~~：拒答层原 20 条构造冲突样本已按用户确认于 2026-08-19 **全部替换**为无召回/弱相关样本（替换脚本：`replace_conflict_samples.py`），pytest 校验通过；
2. **部分术语定义来自公开整理**：个别术语（如非化石能源、可再生能源）的定义为语料化改写，正式使用前建议对照官方原文；
3. **输出长度偏紧凑**：部分 output 为 1~2 句，训练后回答风格可能偏简练，可在抽检时评估是否补充；
4. **重复句式**：同一能力层内部分指令句式相近，可能影响多样性，抽检时留意。

## 4. 抽检要求

- 抽检比例：≥20%（即 ≥60 条），按五能力分层均匀抽样；
- 记录：结论与修正写入 `抽检记录表.md`；
- 修正后：重跑 pytest 校验（5 passed ✅），更新 `train.json`/`val.json`（已重新划分），将版本升为 v1.0。
