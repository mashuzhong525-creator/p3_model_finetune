# P3 训练数据说明

> 生成日期：2026-08-19 ｜ 版本：**v0.1 AI 初稿（未经人工抽检）** ｜ 规模：300 条问答对 ｜ 格式：LLaMA-Factory alpaca（instruction / input / output）
> 素材来源：公开资料整理（绿色建筑评价标准 GB/T 50378-2019 / 2024 年版、双碳政策、碳核算通则），见《素材语料库.md》
> 标注：本数据集为**示例语料**，正式使用请以官方标准与政策原文替换核对（与 P1 现有演示语料口径一致）
> 口径：**现行标准 = GB/T 50378-2019（2024年版）**（2024-10-01 起实施）；数据中"现行版本/当前标准"均按此表述。

## 五能力分层

| 能力层 | 数量 | 占比 | 文件 |
| --- | --- | --- | --- |
| 术语适配 | 60 | 20% | `alpaca_术语适配_60.json` |
| 忠实回答（防幻觉） | 75 | 25% | `alpaca_忠实回答_75.json` |
| 多片段整合 | 45 | 15% | `alpaca_多片段整合_45.json` |
| 证据引用与出处标注 | 60 | 20% | `alpaca_证据引用_60.json` |
| 资料不足拒答 | 60 | 20% | `alpaca_拒答_60.json` |

## 契约约束

- `output` 遵守 P1 C-RAG-ANSWER 输出契约：关键结论后标注 `[证据N]`；仅依据 `input` 片段；片段不足以「资料不足，无法完整回答」收尾；片段未提及的写「资料中未提及」。
- `input` 中的 `[证据N]` 编号与《素材语料库.md》片段对应；拒答样本的片段可能为空、弱相关或互相冲突。
- 拒答层说明：无召回样本 `input` 为空字符串；弱相关样本仅给无关片段。**构造冲突样本已于 2026-08-19 全部替换**为无召回/弱相关样本（见 `replace_conflict_samples.py`）。

## 使用方式

```bash
# 合并并划分 train/val（9:1，固定随机种子）
python split_train_val.py
# 产出：train.json / val.json；随后注册进 LLaMA-Factory dataset_info.json
```

## 质量说明

- 生成过程使用 `../prompts/训练数据构建提示词.md` 的模板，人工抽检记录在过程文档。
- 数据中的数字（星级分数、政策日期、碳市场参数等）均来自公开可查来源，来源列于《素材语料库.md》；因演示需要，个别条目做了语料化改写，正式训练前建议逐条对照官方原文。
