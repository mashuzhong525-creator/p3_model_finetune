# P3 本地微调：代码与参数（LoRA bf16，RTX 5060 8GB）

> 日期：2026-08-19 ｜ 数据：`../data/train.json`（270）/ `val.json`（30），共 300 条
> 说明：本地微调与云端微调使用同一份数据；本页是「本地执行」的代码与参数清单。

## 1. 环境要求

- Windows 11 + RTX 5060 Laptop 8GB（已确认：8151 MiB，空闲可用）
- conda 环境 `finetune`（Python 3.12，已存在，需装 torch 与依赖）
- 基座模型：Qwen2.5-1.5B-Instruct（ModelScope 下载到 `D:\ai_models\Qwen2.5-1.5B-Instruct`）

## 2. 训练参数（LoRA bf16）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 基座 | Qwen2.5-1.5B-Instruct | 约 3.2GB（bf16） |
| 方法 | LoRA bf16 | 不需要 QLoRA/bitsandbytes |
| lora_r / lora_alpha / dropout | 16 / 32 / 0.05 | target_modules = q/k/v/o/gate/up/down |
| max_length | 1024 | 序列上限 |
| batch_size × grad_accum | 4 × 4 | 等效 batch=16 |
| learning_rate | 1e-4 | AdamW，cosine |
| num_train_epochs | 3.0 | 300 条数据，约 20–40 分钟 |
| warmup_ratio | 0.1 | 预热 |
| 评估/保存 | eval_steps=50、save_steps=50、save_total_limit=2 | `load_best_model_at_end` 按 eval_loss 选优 |
| 随机种子 | 42 | 可复现 |

防过拟合：数据量小，重点盯 `eval_loss`（掉头上升即开始记忆）；必要时 epochs 降到 2。

## 4. 执行步骤

### 4.1 搭建环境（一次性）

```powershell
powershell -ExecutionPolicy Bypass -File D:\mashu77\workspace\project1\p3_model_finetune\local_train\setup_local_train_env.ps1
```

预期：末尾输出 `RTX 5060 Laptop GPU 7.96 GB`，无报错。

### 4.2 下载基座模型

```powershell
conda run -n finetune pip install modelscope
conda run -n finetune modelscope download --model Qwen/Qwen2.5-1.5B-Instruct --local_dir D:\ai_models\Qwen2.5-1.5B-Instruct
```

预期：`D:\ai_models\Qwen2.5-1.5B-Instruct` 含 `config.json`、`model-*.safetensors`（约 3.2GB）。

### 4.3 启动本地训练（PEFT 路径，推荐）

```powershell
cd D:\mashu77\workspace\project1\p3_model_finetune\train
.\run_train_local.ps1
```

预期：GPU 检查通过 → `train 270 / val 30 OK` → loss 逐步下降 → 产物 `output\qwen1.5b-lora\`（adapter + trainer_log.jsonl）。

### 4.4 或走 LLaMA-Factory CLI（二选一）

```powershell
.\register_data_local.ps1 -LlamaFactoryData "D:\LLaMA-Factory\data"
conda run -n finetune llamafactory-cli train D:\mashu77\workspace\project1\p3_model_finetune\train\qwen1.5b_lora_local.yaml
```

### 4.5 合并（部署用）

```powershell
python D:\mashu77\workspace\project1\p3_model_finetune\train\merge_peft.py `
  --model_path D:\ai_models\Qwen2.5-1.5B-Instruct `
  --adapter_path D:\mashu77\workspace\project1\p3_model_finetune\train\output\qwen1.5b-lora `
  --output_dir D:\p3\models\qwen1.5b-merged
```

见 `../local_train/本地WSL2-vLLM部署手册.md`（拷合并模型 → `serve_vllm_wsl2.sh` → Windows 访问 8100）。
