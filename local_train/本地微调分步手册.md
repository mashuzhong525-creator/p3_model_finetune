## 阶段 0：前置检查（确认电脑和 conda 就绪）

```powershell
# 0.1 确认显卡被识别（应显示 RTX 5060 Laptop 与约 8GB 显存）
nvidia-smi

# 0.2 确认 conda 可用（应显示 conda 24.x）
conda --version

# 0.3 确认磁盘空间充足（D 盘建议剩余 >50GB，放模型和 LLaMA-Factory）看 D: 那行 remaining
Get-PSDrive -Name D
```

## 阶段 1：创建独立 Python 环境 finetune

```powershell
# 1.1 创建空环境（Python 3.12）
#     注意：如果报 HTTP 404 channel 错误，说明 conda 源里有失效频道，
#           先跳过这里，直接看文末【附：conda 源修复】处理后再回来执行本步。
conda create -n finetune python=3.12 -y

# 1.2 激活环境（每次开新终端跑训练前都要先执行这一条）
conda activate finetune

# 1.3 确认在 finetune 环境里（提示符前应出现 (finetune)）并确认 python 是 3.12
python --version
```

## 阶段 2：安装 PyTorch（CUDA 版，显卡加速必需）

> 关键：不能用普通清华 pypi 源（那是 CPU 版）。必须用带 cuda 的专用源。
> 推荐用我写的一键脚本自动探测可用的源并安装，省去手动试镜像。

```powershell
# 2.1 用一键脚本自动装 CUDA 版 torch（会自动尝试官方/清华/阿里源，只要一个通即可）
python .\local_train\install_torch.py
```

如果你更愿意手动指定源，也可以任选其一（用一次即可）：
```powershell
# 手动方式 A：PyTorch 官方源（CUDA 12.8）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
# 手动方式 B：清华 pytorch-wheels（CUDA 12.8）
pip install torch torchvision --index-url https://mirrors.tuna.tsinghua.edu.cn/pytorch-wheels/cu128
# 手动方式 C：阿里云（CUDA 12.4）
pip install torch torchvision --index-url https://mirrors.aliyun.com/pytorch-wheels/cu124

# 装完验证 GPU 可用（应输出 cuda True + RTX 5060 Laptop GPU）
python -c "import torch; print('cuda', torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'NO CUDA')"
```

## 阶段 3：安装 LLaMA-Factory（训练框架）

```powershell
# 3.1 拉取 LLaMA-Factory 源码到 D:\LLaMA-Factory（会新建该目录）
git clone https://github.com/hiyouga/LLaMA-Factory.git D:\LLaMA-Factory

# 3.2 进入源码目录
Set-Location D:\LLaMA-Factory

# 3.3 以可编辑模式安装（自动带入配套的 transformers/peft/trl 版本）
pip install -e .

# 3.4 确认命令可用（应输出版本号，无 ImportError）
llamafactory-cli version

# 3.5 装 modelscope（用于下载模型）
pip install modelscope
```

## 阶段 4：下载基座模型 Qwen2.5-1.5B-Instruct

```powershell
# 4.1 建模型目录（放在 D 盘，不动 C 盘）
New-Item -ItemType Directory -Force -Path D:\ai_models\Qwen2.5-1.5B-Instruct | Out-Null

# 4.2 用 ModelScope 下载（国内拉模型最快）
python -c "from modelscope import snapshot_download; snapshot_download('Qwen/Qwen2.5-1.5B-Instruct', local_dir='D:/ai_models/Qwen2.5-1.5B-Instruct')"

# 4.3 确认模型文件到位（应有 config.json、model-*.safetensors、tokenizer.json）
Get-ChildItem D:\ai_models\Qwen2.5-1.5B-Instruct
```

## 阶段 6：冒烟验证 + 启动训练（对接已有 run_train.ps1）

```powershell
# 6.0 冒烟验证：先跑极小步数确认整条链路（模型加载/GPU/反向/保存）能通。
#     若这里报 CUDA 不可用或 OOM，先回去做阶段 2/4，别直接开正式训练。
python .\local_train\smoke_test.py --steps 5

# 6.1 正式训练（LoRA bf16，3 epochs，日志 train.log）。
#     会跑较久（几分钟到一二十分钟）。训练时请关闭 Chrome 等大内存程序，给 16GB 内存腾空间。
.\train\run_train.ps1 -LlamaFactoryDir "D:\LLaMA-Factory"

# 6.2 训练后看日志尾部，确认 loss 下降、出现 trainable params 与已保存 checkpoint
Get-Content .\train\train.log -Tail 30

# 6.3 确认 adapter 已产出（应有 adapter_config.json、adapter_model.safetensors）
Get-ChildItem .\train\output\qwen1.5b-lora
```

## 阶段 7：合并 + 转 GGUF + 量化 Q4_K_M（对接已有 export_quantize.ps1）

```powershell
# 7.1 需要 llama.cpp 的 Windows 可执行文件（llama-quantize.exe）。
#     准备方式二选一：
#     (A) 预编译包（推荐，省事）：去 https://github.com/ggerganov/llama.cpp/releases
#         下载 Windows 版，解压到 D:\llama.cpp，确保能定位到 build\bin\Release\llama-quantize.exe
#     (B) 自己编译：git clone https://github.com/ggerganov/llama.cpp.git D:\llama.cpp
#         然后用 cmake / Visual Studio 编译 llama-quantize 目标。

# 7.2 运行合并 + 量化（产出约 1GB 的 qwen1.5b-q4_k_m.gguf）
.\train\export_quantize.ps1 -LlamaFactoryDir "D:\LLaMA-Factory" -LlamaCppDir "D:\llama.cpp"

# 7.3 确认 GGUF 产物大小（约 1GB）
Get-Item .\train\output\qwen1.5b-q4_k_m.gguf | Select-Object FullName, @{n="MB";e={[math]::Round($_.Length/1MB,1)}}
```
